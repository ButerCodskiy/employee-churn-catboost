# Словарь доменных признаков (HR Feature Dictionary)

В рамках Этапа 3 разработан комплекс из 9 доменных признаков, направленных на выявление карьерного застоя, несправедливости вознаграждения, организационной нестабильности и выгорания сотрудников.

| Имя признака | Математическая формула | Бизнес-смысл и интерпретация |
| :--- | :--- | :--- |
| **`Promotion_Stagnation_Ratio`** | $\frac{\text{YearsSinceLastPromotion} + 1}{\text{YearsAtCompany} + 1}$ | **Карьерный застой:** Показывает, какую долю общего стажа в компании сотрудник провел без единого повышения. Чем выше показатель, тем сильнее демотивация. |
| **`Manager_Stability`** | $\frac{\text{YearsWithCurrManager} + 1}{\text{YearsInCurrentRole} + 1}$ | **Стабильность руководства:** Показывает, насколько руководитель нов для сотрудника в рамках его текущей позиции. Резкое падение указывает на смену менеджмента (потенциальный конфликт с новым шефом). |
| **`Relative_Income_to_Role`** | $\frac{\text{MonthlyIncome}}{\text{Median}(\text{MonthlyIncome} \mid \text{JobRole})}$ | **Справедливость оклада по роли:** Отношение зарплаты сотрудника к медиане коллег той же должности. Значения $< 1.0$ сигнализируют о недоплате по рынку внутри грейда. |
| **`Relative_Income_to_Dept`** | $\frac{\text{MonthlyIncome}}{\text{Median}(\text{MonthlyIncome} \mid \text{Department})}$ | **Справедливость оклада по департаменту:** Относительный вес сотрудника в фонде оплаты труда подразделения. |
| **`Overall_Satisfaction`** | $\text{EnvSat} + \text{JobSat} + \text{RelSat}$ | **Интегральный индекс лояльности:** Сумма оценок (1–4) удовлетворенности средой, работой и отношениями. Позволяет уловить кумулятивную неудовлетворенность. |
| **`Burnout_Index`** | $\text{OverTime} \times (5 - \text{WLB}) \times (\text{Travel} + 1)$ | **Индекс риска выгорания:** Мультипликативный фактор сверхурочных работ, дефицита баланса личной жизни (WLB) и частоты командировок. |
| **`Tenure_to_TotalWorkingYears`** | $\frac{\text{YearsAtCompany} + 1}{\text{TotalWorkingYears} + 1}$ | **Организационная привязанность:** Доля профессионального стажа, проведенная в данной компании. |
| **`Tenure_to_Age`** | $\frac{\text{YearsAtCompany}}{\max(\text{Age}, 18)}$ | **Нормированный стаж:** Отношение времени в компании к возрасту сотрудника. |
| **`Company_Hop_Frequency`** | $\frac{\text{NumCompaniesWorked}}{\max(\text{TotalWorkingYears}, 1)}$ | **Склонность к частой смене работы («джоб-хоппинг»):** Среднее число работодателей в расчете на один год общего стажа. |

---

## Архитектурные гарантии защиты от утечек (Data Leakage)
1. Групповые медианы для `Relative_Income_to_Role` и `Relative_Income_to_Dept` вычисляются **строго на обучающей части конкретного фолда кросс-валидации** (`fit` трансформера).
2. На валидационных и тестовых фолдах (`transform`) значения только маппятся с безопасным заполнением глобальной обучающей медианой для редких/новых категорий.
